This project solves the problem of people in tech especially students who doesn't know how to improve, what courses to learn, which kind of jobs they can apply to, what's their weakness points by building a website that makes a exam for the user, this exam tests the user in all the aspects, for example: algorithims, writing code, frontend skills, backend skills.... etc, then it gives a feedback and points at the weakness points, gives the user the skills they need to improve according to the priority and reccommends courses for it. then it gives suggestions about the name of jobs u can apply to e.g: data anlysis engineer, frontend engineer, ai enginner, devops developer, game tester... etc
