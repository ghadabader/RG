# Intent 0001 — Auth (sign up / log in / log out)

Derived from PRD requirement 0001, rank 3.

PROBLEM:  A user's diagnostic profile and history must persist across visits and retakes,
which only works with a real account — without one, every attempt would be a disconnected,
throwaway session.
USER:     Any tech learner about to start their first assessment, or return for a retake.
OUTCOME:  A visitor can create an account, log in, and log out; a logged-in session is what
every other feature (exam, report, history, settings) is scoped to.
SUCCESS:  A new user can go from landing page to a logged-in session in under a minute,
with no more friction than email + password.
LIMITS:   No data selling; account creation asks for only what's needed (email + password),
consistent with the anonymization commitment in CLAUDE.md.
NOT NOW:  Social login (Google, etc.) — deferred; enterprise/SSO login is also not now.

## Open questions
- Email/password only, or also social login? Not chosen — email/password is the safe
  default to build first since it needs no third-party OAuth setup.
